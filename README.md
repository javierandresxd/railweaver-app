# Railweaver · páginas públicas

Política de privacidad y soporte de Railweaver, de Kaha Innovations SpA. Se
publican con GitHub Pages porque App Store Connect y Google Play exigen una
dirección pública para cada una.

- [Política de privacidad](https://javierandresxd.github.io/railweaver-app/privacidad.html)
- [Soporte](https://javierandresxd.github.io/railweaver-app/soporte.html)

Las dos salen del repositorio del juego, en `legal/`: la política se genera
desde `legal/privacidad.md` y `legal/privacy.md` con `scripts/privacidad.mjs`,
y el soporte es `legal/soporte.html`. Si hay que cambiarlas, se cambian allá y
se copia aquí el resultado; no se editan estos archivos a mano.
